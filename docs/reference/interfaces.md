# Data and boundary interfaces

Interfaces fill in what depends on the run: they write input grids and boundary spectra from data sources, and set the times of the computation and output from the run period.

## `rompy_swan.interface`

::: rompy_swan.interface
    options:
      show_root_heading: false
      heading_level: 3

## `rompy_swan.data`

::: rompy_swan.data
    options:
      show_root_heading: false
      heading_level: 3

## `rompy_swan.boundary`

::: rompy_swan.boundary
    options:
      show_root_heading: false
      heading_level: 3
