# Config

[`SwanConfig`][rompy_swan.config.SwanConfig] is the SWAN model configuration. It gathers the components, one per SWAN command or group of commands, and renders the SWAN command file (`INPUT`). It subclasses rompy's [`BaseConfig`][rompy.core.config.BaseConfig].

::: rompy_swan.config
    options:
      show_root_heading: false
      heading_level: 2
