# Installation

You need two things: the rompy-swan Python package, which writes SWAN workspaces, and SWAN itself, which runs them.

## rompy-swan

rompy-swan needs Python 3.10 or later. It installs [rompy](https://rom-py.github.io/rompy/) and its other dependencies.

```bash
pip install rompy-swan
```

These docs describe the development version on the `main` branch, which has fixes and features not yet released. To install it from GitHub:

```bash
pip install "rompy-swan @ git+https://github.com/rom-py/rompy-swan.git"
```

### Optional extras

| Extra | Adds | Needed for |
|---|---|---|
| `docs` | [rompy-docs](https://github.com/rom-py/rompy-docs) | Building these docs |
| `test` | pytest and test tools | Running the tests |
| `dev` | pytest, ruff, mypy, coverage | Development |

## SWAN

rompy-swan writes the SWAN command file and input files but does not include SWAN. There are two ways to run it.

### Docker (recommended)

The public image `ghcr.io/rom-py/swan` contains SWAN built with NetCDF output, in serial and MPI builds. You only need [Docker](https://docs.docker.com/get-docker/).

| Tag | Contents |
|---|---|
| `41.51` | SWAN release 41.51 |
| `latest` | The newest release |

Pin a version tag for reproducible runs, since `latest` moves when a new release is published. Every image is tested with workspaces generated by rompy-swan before it is published. [Running SWAN](../user-guide/running.md) shows how to use it.

!!! note "NetCDF output"
    The official image from the SWAN team, `delftwaves/swan`, is built without NetCDF, so it writes `.nc` output files as text. Use `ghcr.io/rom-py/swan`, or your own build with NetCDF, if your output files end in `.nc`.

### Your own SWAN

Download and compile SWAN from the [SWAN website](https://swanmodel.sourceforge.io/), and make sure the `swan.exe` executable is on your `PATH`. Build it with NetCDF support (the `NCF` switch) to write NetCDF output.

## Check the installation

```python exec="on" source="above" result="text"
import rompy
import rompy_swan

print(f"rompy {rompy.__version__}, rompy-swan {rompy_swan.__version__}")
```
